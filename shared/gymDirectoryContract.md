# Gym API contract — final

Types live in `shared/gymDirectory.ts`, router at `trpc.gym.*`. Personal-tool `ownerProcedure` remains public, but all DB operations use fixed owner ID 2; input never accepts userId. This feature does not query exercises or modify any existing health/workout rows.

| API               | Input                                                                                                           | Result                                                                                                                                                        |
| ----------------- | --------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| search            | `{query,country?,limit?:1..50,offset?:0..1000000,pageToken?}`                                                   | `{results:GymLocation[],total,source,providerStatus,providerWarning?,providerHasMore,nextPageToken?,attribution:'Google Maps'\|null,completeWorldwide:false}` |
| getSaved          | none                                                                                                            | `GymLocation[]`                                                                                                                                               |
| saveLocation      | `{name,address,country?,brand?,sourceUrl?,placeId?,latitude?,longitude?}`                                       | `GymLocation` with numeric `id`/`savedId`                                                                                                                     |
| getEquipment      | `{gymId:number\|string}`                                                                                        | `GymEquipmentResult`, including official snapshot separately                                                                                                  |
| getMachineCatalog | none                                                                                                            | exact selectable options `{machineKey,displayName,nameZh,equipment,aliases,guideId,primary,secondary,primaryLabels,secondaryLabels,referenceUrls}[]`          |
| upsertEquipment   | `{gymId:number,machineKey,displayName,equipment,source:'owner_confirmed'\|'photo_confirmed',notes?,sourceUrl?}` | one `GymEquipmentRecord`                                                                                                                                      |
| deleteEquipment   | `{id:positiveInteger}`                                                                                          | `{success:true}`, missing/foreign => NOT_FOUND                                                                                                                |

Search total is the current combined official+saved+provider-page result count, not worldwide completeness. Offset paginates that set. NextPageToken changes the Google provider page; reset offset to 0, append and dedupe in UI. Google tokens may take a short time to activate: INVALID_REQUEST stays visible; retry later. Official/saved matches remain during provider outage. Empty query lists official/saved without a provider request. Country values follow reviewed seed region codes HK/CN/MO/SG/TW. Localized official name/address aliases are searched. Google Maps attribution must stay visible with provider results.

Official result IDs are `official:${seed.id}` (the seed ID may contain namespaces, e.g. `official:247fitness:HK:membership-tree:123`). Raw `247fitness:*` IDs are also accepted for read-only getEquipment. Google ephemeral IDs are `google:${placeId}`; explicitly save first before getEquipment on a Google result. Numeric saved IDs are required for owner equipment writes.

Save is explicit and idempotent per owner+provider key or normalized Unicode name/address. Source URLs must be public HTTPS without embedded credentials/key/token params. Coordinates must be finite and paired or omitted if unknown. All provider search results, geometry, timestamps and page tokens stay ephemeral: no search writes. Explicit saved provider selection is owner-maintained address text; Google geometry/automatic metadata are not persisted (no automatic metadata cache/TTL introduced). Place IDs can be retained. Owner-entered or reviewed official coordinates can be persisted. No automated Google refresh, no bulk provider persistence.

## Official snapshot shape

Parent-owned `shared/gymOfficialInventory.ts` exports `GYM_OFFICIAL_INVENTORY: GymOfficialInventorySnapshot[]` (Record keyed by gymReferenceId also supported). Each snapshot is `{gymReferenceId,branchName,country,checkedAt,sourceUrl,status:'verified'|'unknown',machines}`. Reference ID equals raw `GymOfficialSeed.id`, without `official:` prefix. Each machine is `{id,name,nameZh?,manufacturer:string|null,model:string|null,category:string|null,total:number|null,normal:number|null,damaged:number|null,sourceUrl}`. No machineKey assignments or guessing from category. Only exact case/space-normalized official names against narrow GYMWORK_REFERENCES aliases produce suggestions; unknown names remain visible. `normal===0` or `total===0` yields no suggestion. Null quantity includes explicit `availabilityCaution` requiring on-site verification.

`getEquipment` returns `{gym,equipment,officialEquipment,officialInventory,availableExercises,coverage}`. OfficialEquipment contains raw static names/counts, not DB rows; officialInventory is `{sourceUrl,checkedAt,status:'verified',gymReferenceId}|null`. Published zero rows/unknown status remain unknown. Official snapshots match only the exact official ID, normalized full name+address, or source URL unique to one reviewed seed; never a generic brand/directory URL. Branch reference ID/country must match.

Owner equipment records remain numeric and deletable; official snapshot items are not deletable. Suggestions have `equipmentId:number|string`, `confirmationSource:'owner_confirmed'|'photo_confirmed'|'official_inventory'`, optional `availabilityCaution`, exact action aliases, canonical `primary/secondary`, and Chinese `primaryLabels/secondaryLabels`. Owner confirmation wins over the same exact official machine key. Related actions are never silently substituted.

Coverage is `{status:'unknown'|'partially_confirmed'|'official_snapshot',confirmedEquipmentCount,officialEquipmentCount,mappedEquipmentCount,unmappedMachineKeys,completeInventory:false,message}`. Show dated official attribution and on-site verification warning; verified means dated publication, NOT complete/current inventory. Timestamp strings are ISO UTC; display Asia/Hong_Kong.

DDL: `drizzle/20261115_gym_directory.sql` is additive only; parent reviewed/applied it. No old table changes or workout session.location rewrites. Frontend may pass a selected address on a new session action only.
