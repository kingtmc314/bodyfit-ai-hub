# 跑步情境連結與按日期交叉驗算

2026-11-15 香港時間；現行版本 3.17.3 的程式審核與新增功能依據。

現行能量實驗室使用與項目相容的歷史摘要／合資格 FIT 配速、最新身體資料及最新靜止心率。天氣輸入會透過固定教育性負荷公式調整時間。歷史資料轉為 LabHistoricalRun 時未保留 weather，也沒有連結逐次跑步前的睡眠或靜止心率。最新靜止心率影響模擬心率與恢復，並不等於睡眠／恢復已納入配速預測。getAIAnalysis 的全歷史上下文含每次跑步天氣及 FIT 心率特徵，但沒有睡眠／每日靜止心率的逐次連結，也沒有樣本外誤差比較。

擬新增只讀、可追溯的逐次情境連結及按香港日期前推驗算。每個測試日只使用更早的跑步及健康量測；同日所有活動一併留出，避免先讀答案。訓練標準化及缺值處理只能在訓練集上計算。分開訓練類型、路面及距離，缺值不當零，間歇／慢跑配速不當作比賽極限能力。先比較相同留出活動上的歷史中位配速與情境模型誤差；無充分樣本外改善，不啟用額外速度修正。來源選擇待用戶確認；不搬移或改寫任何健康資料。

天氣研究指出溫度、濕度、風與輻射的關聯具項目差異；不直接把精英賽事百分比套至所有個人訓練。[1] 睡眠共識指出完全不眠對表現有負面證據，但短期部分睡眠限制的效果並不一致，消費級裝置亦有量測限制。[2] 因此不採『少睡一小時固定慢若干百分比』或醫療診斷。
