# v3.14.2 歷史天氣資料來源

BodyFit 的跑步及比賽歷史資料回填使用 Open-Meteo Historical Weather API：

- 官方文件：https://open-meteo.com/en/docs/historical-weather-api
- API endpoint：`https://archive-api.open-meteo.com/v1/archive`
- 要求 `timezone=Asia/Hong_Kong`，讓逐小時回應以香港日期和時段選取。
- 使用的逐小時欄位：`weather_code`、`temperature_2m`、`relative_humidity_2m`、`apparent_temperature`、`precipitation`、`wind_speed_10m`。
- 歷史來源為再分析資料，能提供自 1940 年開始的逐小時天氣；不是氣象站原始觀測。前端會以「歷史天氣」標示來源，並保留可手動編輯欄位。
- WMO weather code 由應用程式映射為繁體中文狀況，例如晴朗、多雲、小雨、大雨、雷暴。

實作規則：批量工具先預覽，再確認；預設只補齊空白欄位，未來日期跳過；使用者可選擇日期範圍、跑步／比賽範圍、位置與是否覆寫。
