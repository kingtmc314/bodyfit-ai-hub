# GPX／TCX 原始跑步檔解析依據

GPX 1.1 將軌跡表示為 `trk`、`trkseg` 與有序 `trkpt`。每一點可帶有時間與海拔；它亦允許 vendor extensions，因此 Garmin 心率、步頻與功率資料可能位於擴充節點。實作會在有座標但沒有累積距離時，從 WGS84 點位計算累積距離，並僅在可用時間與距離同時存在時推算區段配速。

TCX 是 Garmin Training Center XML 活動格式。其 `Trackpoint` 可提供 `Time`、`AltitudeMeters`、`DistanceMeters`、`HeartRateBpm/Value` 與 `Cadence`；`Lap` 可提供總時間、距離、卡路里及平均／最大心率。實作將這些欄位對應到既有 Garmin 原始檔摘要、分段與 time-series 合約。

上載限制維持 25MB。為避免外部實體與大型 XML DOM 的安全風險，實作使用 strict SAX 事件解析，拒絕帶有 `DOCTYPE` 或 `ENTITY` 的 XML，且不讀取外部內容。
